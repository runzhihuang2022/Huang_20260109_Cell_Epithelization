# GitHub package notes

One-command entry point:

```bash
python run_figure2.py
```

Set `FIGURE2_STEREO_PDF_OUTPUT`, or set `FIGURE2_19DPB_P1_H5AD` and
`FIGURE2_19DPB_P1_ANCHORS` separately. Large AnnData, masks, experimental
images and final submission binaries are intentionally excluded. The
scientific and statistical caveats in `STATISTICAL_AUDIT.md` remain binding.
