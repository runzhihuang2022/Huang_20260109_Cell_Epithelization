# Source-data provenance

Files in this directory are unchanged copies of the 2026-07-15 Figure 5 reanalysis outputs. Their original location is recorded as `DATA002` in `../data_manifest.csv`.

- `Figure5A_B_*`: section-aware nearest-neighbor permutation results.
- `Figure5C_*`: candidate ligand-receptor permutation results.
- `Figure5D_*`: IGFL1 wound-axis correlations.
- `Figure5E_*`: IGFL1/IGFLR1 spatial-correlation permutation result.
- `FigureS5A_C_*`: IGFLR1 Fib_K14 versus other-fibroblast comparison.
- `FigureS5E_F_*`: transcriptomic-marker proxy NN analysis; this is not microscopy quantification.
- compressed expression/metadata tables: panel-regeneration inputs.

Do not overwrite these copies. Derived plotting tables should be written to `../outputs/tables/` or `../supplements/tables/`.
