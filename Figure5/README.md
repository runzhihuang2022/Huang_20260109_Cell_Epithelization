# Figure 5 + Figure S5 finalization package

This directory is the joint evidence unit for Figure 5 and Figure S5.

## Start here

1. `SCIENTIFIC_CONFLICT_AUDIT.md` — material claim/data conflicts requiring a decision.
2. `panel_manifest.csv` — one row for each Figure 5A–I and Figure S5A–M panel.
3. `data_manifest.csv` — source paths, subsets, observational units and missing assets.
4. `CHANGE_SPECIFICATION.md` — typography, layout and delivery requirements.
5. `LAYOUT_BLUEPRINT.md` — proposed A4 panel geometry.

The current package is an audited pre-assembly state, not a final figure. It deliberately contains no final AI/composite because the unresolved items would change scientific meaning.

## Data boundary

Human Stereo-seq analyses must use only the explicitly registered 11-section project subset. The 19dpb evidence currently uses the registered `19dpb` and `19dpb_p1` sections. Bin-level measurements and biological sections are kept separate in all inferential statements.
