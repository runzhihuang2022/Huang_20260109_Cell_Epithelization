# Huang_20260109_Cell_Epithelization

Reproducible analysis and visualization code for the epithelialization manuscript figures.

Each figure is organized in a separate folder with its own code, source tables, legend, and rebuild instructions.

Current supplemental-figure revision packages:

- [`FigureS4_revised_v01`](FigureS4_revised_v01): human scRNA-seq and Stereo-seq analyses supporting Fib_K14 identification.
- [`FigureS5_revised_v01`](FigureS5_revised_v01): animal-only burn-model and experimental-validation panels.
