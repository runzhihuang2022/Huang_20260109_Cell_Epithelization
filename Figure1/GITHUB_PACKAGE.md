# GitHub package notes

Run `python run_figure1.py` after configuring the input paths documented in
`README.md`. The repository contains scripts, manifests, small derived tables,
legends and QC records. Raw H5AD objects, clinical photographs, histology,
microscopy, TIFF/PDF/AI submission files and caches are intentionally excluded.

The human Stereo-seq analysis must remain restricted to the 11 sample IDs
recorded in `source_data/Figure1EF_score_provenance.json`.
