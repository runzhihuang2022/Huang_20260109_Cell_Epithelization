# GitHub package notes

One-command entry point:

```bash
python run_figure3.py
```

The repository contains plotting/assembly code, manifests, small derived
tables, legends and QC. Raw flow-cytometry files, AnnData, microscopy,
PowerPoint/PDF/AI/TIFF assets and blocked experimental panels are not included.
Read the scientific-status section of `README.md` before interpreting outputs.
